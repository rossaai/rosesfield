# Security

Rosesfield holds your Comfy key, and a public host runs on each visitor's own key, so a flaw that leaks a key or spends one is the kind of report that matters most.

## Report a vulnerability

Use **Report a vulnerability** on the repository's Security tab. The report stays private between you and the maintainers. Do not open a public issue for it.

Include what you did, what you saw, and the commit or release you ran. The maintainers answer in the report.

## Supported versions

The latest release and `main` get fixes.
